# Study Log

> 每次学习 session 追加一条记录，不覆盖旧记录。

| 日期 | 科目 | 状态 | 本次重点 |
|---|---|---|---|
| | | | |

## 状态说明

- 开始：本次 session 已开始
- 完成：本次 session 正常完成
- 未完成：本次 session 中途停止

## 使用规则

- 每次开始学习时，先在对话第一行显示“日期｜科目”。
- 同时写入一条“开始”记录。
- 正常结束后更新为“完成”。
- 中途停止时可更新为“未完成”。
- 同一天同一科多次练习，分别记录。
- 没有记录的日期视为没有进行本 Skill 管理的学习。
