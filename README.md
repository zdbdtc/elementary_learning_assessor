# elementary-learning-assessor

一个面向小学生的多学科学习效果检测 Skill。

## Compatibility

Compatible as a prompt-based skill with ChatGPT, Claude, DeepSeek, Kimi and other LLM agents. Native installation paths vary by platform.

本 Skill 以能力判断和替代流程为主，不要求某个平台特有的语音、联网、图片检索或云端连接功能。

## 使用方式

把整个文件夹放进支持读取 Skill / 项目文件的环境中。

如果当前环境不能“安装 Skill”，也可以把这些文件作为上下文或项目文件上传，然后要求学习助手：

> 按 elementary-learning-assessor 的规则检查今天的数学。

或：

> 按 elementary-learning-assessor 做一次英语学习检查，包含听力、口语和对话。

## 推荐输入

- 当前教材/年级
- 当前页码或章节
- 最近几页教材照片
- 学校作业或试卷错题照片
- 考试范围

不需要家长每天自己拆知识点。
Skill 会根据教材范围、错题和历史掌握状态决定检测内容。

## 学习日期记录

每次学习开始时先显示日期和科目，并在 `progress/study_log.md` 中记录开始/完成状态。

## 单科时长

每科每次学习目标约 30 分钟。学习助手应按孩子实际完成速度、正确率和疲劳程度动态调整题量，不机械凑时长。

## 主动学习方法

数学首次答错先让孩子自查订正；自查后仍错、同类错误反复，或孩子说不知道/求助时，再用苏格拉底式追问，一次只问一步。关键概念适量用费曼式解释验证；国語适量使用。中文与英语当前以非母语学习为前提，优先检查语言元素的理解、使用、听说读写和迁移，不强求解释语法原理。

## 最新交互规则

- 每次正式出题前，简短确认当天有无纸笔、可用的电子笔，以及能否提交照片、截图或可见笔迹；本次已说明则不重复问。
- 根据当前工具安排题型：纸笔和电子笔都可用于手写、画图、圈选和标注；无工具时改用口头或文字等方式，不能检查的书写/作图能力保留待验证。
- 默认按题组出题，而不是一次一题。
- 每组可包含多道题；首次错误先给一次自查订正机会，重复错误或孩子说不知道/求助时才切换到单题引导。
- 自查改对后具体鼓励，通常用 1 道简短变式复查后回到正常节奏；不把一次错误直接归为“粗心”，也不因此自动降低掌握等级。追问仍无进展时改用小提示或简短讲解，不反复盘问。
- 数学面向孩子全部使用日语。
- 数学基础计算题直接显示算式，竖式直接排版。
- 中文日常不安排单独写字题；作文中用拼音代替已学汉字时，指出该字所在的教材书名和页码，再进入组词手写并拍照复查流程。
- 中文回答方式约 50% 文字输入、50% 口头回答。
- 中文加入“朗读题目 → 简化中文 → 日语解释任务要求”的理解援助阶梯。
- 当前环境支持音频时，中文可进行古诗语音背诵；不支持时改用家长朗读或文字任务。中文也支持随机诗句默写。
- 英语将语音口答作为常规题型，加入“如果想问今晚吃什么，用英语怎么说？”等生活情景表达、看图说名词/动作和短对话；根据表现从单词、短语逐步过渡到完整句子，不要求先会认字或打字，不提前展示参考答案。
- 按实际能力分别使用语音输入、设备语音转文字、图片检索或简单情景绘图；看图既可练物体名称，也可练“在做什么”。无法使用图片或语音时，用上传图片、身边实物、家长转述或文字替代；只收到转写时不评价发音。听力仍须实际播放音频，换图/换情景复查，示范跟读不算独立掌握。
- 四科都支持上传作业或错题照片，完成错因评价、本人订正、变式复查和进度记录。
- 数学支持从照片或电子手写截图分析错误步骤、手写订正、重新上传和变式复查；工具合适时加入列竖式、画图、连线和标注题。
- 中文和国語只评价网课布置后上传的作文，重点反馈优点、语法、连接词、重复句式和可加强之处，默认不另出作文题。
- 当前环境支持云端存储访问时，Skill 可从私有的四科文件夹读取错题；模板以 Google Drive 为示例。环境不支持时，可直接上传文件或提供可读取的共享链接。
- 资料库的 `Y 学年` 默认为当年 4 月 1 日至次年 3 月 31 日，其下 1–3 月文件夹属于 Y+1 年；查找和排序先换算为公历日期，不把上传/修改时间当成作业日期，也不改动原文件夹。
- 可依据孩子的年级和兴趣适度个性化题目，并在开场、题组反馈和订正时增加简短、有趣且具体真实的鼓励；数学和国語的鼓励用日语，不用闯关或奖励压力诱导多做题。
- 学校名称、兴趣、云端文件夹链接和真实学习记录不写入公开代码仓库；仓库只保存模板与规则。
- 30 分钟 session 优先按真实开始时间计时；无法读取真实时间时才估算。
