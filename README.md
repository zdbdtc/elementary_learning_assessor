# elementary-learning-assessor

一个面向小学生的多学科学习效果检测 Skill。

## 文件结构

```text
elementary-learning-assessor/
├── SKILL.md
├── references/
│   ├── google-drive.md
│   └── personalization.md
├── profile/
│   └── learner-profile.template.md
├── subjects/
│   ├── chinese.md
│   ├── japanese.md
│   ├── math.md
│   └── english.md
└── progress/
    ├── progress.md
    └── study_log.md
```

## 使用方式

把整个文件夹放进支持读取 Skill / 项目文件的环境中。

如果当前环境不能“安装 Skill”，也可以把这些文件作为 Project 文件上传，然后要求 AI：

> 按 elementary-learning-assessor 的规则检查今天的数学。

或：

> 按 elementary-learning-assessor 做一次英语学习检查，包含听力、口语和对话。

## 推荐输入

- 当前教材/年级
- 当前页码或章节
- 最近几页教材照片
- 学校作业或试卷错题照片
- 考试范围

不需要家长每天自己拆知识点。
Skill 会根据教材范围、错题和历史掌握状态决定检测内容。

## 学习日期记录

每次学习开始时先显示日期和科目，并在 `progress/study_log.md` 中记录开始/完成状态。

## 单科时长

每科每次学习目标约 30 分钟。AI 应按孩子实际完成速度、正确率和疲劳程度动态调整题量，不机械凑时长。

## 主动学习方法

数学优先使用苏格拉底式追问和费曼式解释验证；国語适量使用。中文与英语当前以非母语学习为前提，优先检查语言元素的理解、使用、听说读写和迁移，不强求解释语法原理。

## 最新交互规则

- 默认按题组出题，而不是一次一题。
- 每组可包含多道题；出现错误或卡住时才切换到单题追问。
- 数学面向孩子全部使用日语。
- 数学基础计算题直接显示算式，竖式直接排版。
- 中文日常不安排单独写字题；作文中用拼音代替已学汉字时，进入组词手写并拍照复查流程。
- 中文回答方式约 50% 文字输入、50% 口头回答。
- 中文加入“朗读题目 → 简化中文 → 日语解释任务要求”的理解援助阶梯。
- 中文支持古诗语音背诵与随机诗句默写。
- 英语初学阶段以听力、看图口答和短对话为主，根据听懂、说出和认词的表现调整文字任务。
- 英语支持主动找照片、听词选图和看图说词；换照片复查，示范跟读不算独立掌握。
- 四科都支持上传作业或错题照片，完成错因评价、本人订正、变式复查和进度记录。
- 数学支持从作业照片分析错误步骤、纸上订正、重新上传和变式复查。
- 中文和国語只评价网课布置后上传的作文，重点反馈优点、语法、连接词、重复句式和可加强之处，默认不另出作文题。
- Skill 可从私有 Google Drive 的四科文件夹读取错题；准确文件夹链接保存在私有学习者资料中。
- 可依据孩子的年级和兴趣适度个性化题目，并使用具体、真实的鼓励。
- 学校名称、兴趣、Drive 链接和真实学习记录不写入公开 GitHub；仓库只保存模板与规则。
- 30 分钟 session 优先按真实开始时间计时；无法读取真实时间时才估算。
