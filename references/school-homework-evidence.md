# 学校作业：老师首次批改与学习表现证据

读取学校作业、测验或老师批改照片，用于能力判断、错因复盘、知识点映射或出题选取时，先执行本文件。**既有文件夹中的作业也要分析老师首次批改，不能只抽取题型。**本文件规定证据读取与记录方式；各学科的学习语言、题量、难度和独立掌握条件仍按 `subjects/*.md` 执行。

## 1. 分别保留题型来源与学习表现

- 静态知识索引与来源核查报告回答「教过／考过什么」；老师首次批改及孩子原答回答「这次怎样完成」。两类证据分别存储，不能从索引的学校实证标签推断孩子答对。
- 将已核实的学校学习表现追加到该学科原有私有 `progress.md`、`study_log.md`，必要时另附逐题证据表，由两文件引用。保留原始成绩、订正、提示和最高已确认能力，不重建动态档案，不把能力状态塞进静态索引。
- 学校作业与学习助手题单是两种来源。**学校作业照片不自动满足某份已交付题单的答卷门槛**；只有确实对应那份题单的真实答案才满足。作废题单／无效题的排除规则继续生效。

## 2. 先核实首次批改，再按最小答题单位判定

1. 确定原始文件、页／面、题号及小问，区分印刷题面、孩子原答、老师首次批改、孩子订正、老师复批和家长标注。不凭红色或某一种颜色直接认定书写者或批改先后。
2. **确认老师已完成这一范围的首次批改且该答题单位完整可见**，再执行下表。批次先后可以由真实原始／订正照片、明确记录或可靠可见证据确认；不能把当前最终照片上的圈一律当成首次圈。
3. 优先判定最小可评分单位（一个空、小问、算式、图或明确要求）。大题包含多个必答小问时，只有全部小问首次完整正确才把整题记为首次完整正确；不把一个圈推广到未被覆盖的小问。

**整组圈的范围**：老师明确给整个计算栏、连线组或大题画一个圈时，保存这一明确范围的**组级首判**。不能因为组内各格没有小圈就机械逐格判错，也不能把一个组级圈拆成多个独立正确样本；组内具体小问的独立表现仍须各自证据。圈的覆盖范围不清时保留待核实。

| 已核实的老师首次批改痕迹 | 记录状态 |
| --- | --- |
| 明确的首次圈，且该单位没有老师划线或评论 | 老师首判正确；独立性另查 |
| 首次没有画圈 | 首判错／未完整；记录「无圈」及可见原答 |
| 首次有老师划线或与该单位相关的评论，无论同时有无圈 | 首判错／未完整；保留划线位置与评论原文，不自行添加正面评论豁免 |
| 首次是否批完、圈归属、批次先后或关键笔迹无法可靠确定 | 首判待核实；不计入已确认正确或错误分母 |

- 上述「无圈算错」以**已经完成首次批改、该单位完整可见**为前提；未批、漏拍、遮挡、未见首批或只见订正后的圈，均不能据此猜成错或对。
- 不把题面印刷线、孩子草稿／划改、家长笔迹当成老师划线。记录评论的归属范围；姓名、日期、整页鼓励章等不属于某一答题单位的标记，单列为页面标记，不能任意分派成每一小题的评论。整页且明确针对答题质量的评论保留原文和范围，不臆测其具体对应题号。
- 后来订正得到圈、整页最终全圈或最终分数，不覆盖首次错误。首判明确为错但原答已擦去时，可记首判错，原答／具体错因记「无法还原」，不从正确订正倒推原错。
- 老师判定与对可见原答的独立核算不一致时，两项并列保存并标「判定冲突待核查」；不得静默改写老师首判，也不得用老师圈替代对数学正确性和明示要求的核对。确认题目自身无效时按无效题排除，保留排除理由。

## 3. 接入掌握状态、难度与复查权重

- **老师首判正确不等于已证实无提示独立完成。**另列独立性：已核实独立／已知提示或协助／未知。没有证据时填未知，不能由老师画圈、笔迹整齐或答案正确反推独立性。
- 数学中，老师首判正确可作为该具体题型的「校内 L0 正确证据」；独立性未知时保留为「校内首判正确，独立掌握待验证」，不直接授予最高已确认独立 L 等级。确有无提示独立证据的学校作答可与其他有效作答一起满足相应级别条件，不把 AI 训练作为唯一证据来源；仍须按数学规则独立首答及无提示变式／跨天复查，不把校内 L0 推成 L1 以上。
- 老师首判错／未完整参与知识点薄弱项和复查权重，但把「老师判错事实」「可观察错误」「错因推测」分开。漏单位、书写要求、概念、运算、读题或原因不明分别记录，不能统称粗心或概念不会。
- 按真实作业日期、题型、难度及后续独立表现合并判断。新发现的旧错记为历史证据，不计作审核当天的新错误；有更晚稳定独立证据时保留该能力，仅安排必要的间隔复查，不机械降级或抹去已有 L 等级。
- 当前月数学⑥～⑩继续严格匹配当前月学校难度；老师首判对错可影响同难度题型的选择与复查重点，**不触发当月拔高**。月份转换按 `cloud-storage.md` 的日本学年规则，转历史后也不自动升级。
- 一题可关联多个真实知识点ID，但在总成绩中只计一次；知识点统计说明其为关联证据，不能把多ID相加当总题数。复合题无法精确对应ID时保留题型标签与证据，标「未建立精确ID映射」，不强套相近ID。

## 4. 私有逐题记录与去重

每条学习表现至少保留：

| 字段 | 记录要求 |
| --- | --- |
| 来源 | 学科、教材／册次、学年与公历月份、原始文件稳定标识及私有定位、页／面、题号／小问 |
| 日期 | 实际作业日期、首次批改日期（可知时）、本次审核日期分别记录；缺日期填未知／仅确认年月，上传时间不代替学习日期 |
| 对应能力 | 稳定知识点ID或未映射题型标签；数学写明学校 L0 的题型、范围、步骤与作答要求 |
| 首次证据 | 原答、首次圈／无圈／划线／评论、首批完成及顺序依据、首判正确／错或未完整／待核实 |
| 后续证据 | 订正与复批结果、提示／协助情况、独立性证据、后续独立变式；分别记录，禁止覆盖首判 |
| 当前决策 | 已确认最高能力／L级、待验证能力／L级、错因、权重和下一次适合题型，注明判断依据 |
| 审核状态 | 已核实、部分可核实、待核实、无效排除；范围、缺口与冲突原因 |

- 同一张已完成纸面的不同照片、裁图、重上传、原答与订正照合并到同一学习事件；文件ID不同不等于新练习。以题面、孩子笔迹、日期及批改痕迹确认同一纸面，保留所有来源引用。
- 去重须跨本次已核查的历史／当月目录执行：同一张历史已作答纸即使出现在当前月文件夹，也不能仅凭目录位置认定为当月新增教学、当月作答或当月教学进度。先核实真实作业日期及当前月其他可靠学校证据；无法确认时保留来源冲突／月份待核实，不重复计分，不把旧题冒充当月题。
- 仅题面相同而孩子确实在不同日期重新独立完成的，是不同事件；证据不足时不擅自去重或重复计数。已审核文件只核对新增／变化信息，首次批改不可被后续版本覆盖。
- 学校首判统计与学习助手题单首答统计**分别列分母和口径**。学校首判待核实、尚未批改及无效题不纳入学校已确认首判分母；同时报告未确认数，不能只显示被确认部分而声称整页全对。
- 学校作业不能改写既有10题题单成绩；订正不计新首答次数。实际用时未知就留未知，不以照片或审核时间补造。

## 5. 既有资料补录与日常执行

- 既有作业也适用；按已授权学科目录及本次范围补录。在私有记录标明已核查哪些文件／题目、哪些尚未看首批原图，不能把题型索引已核验或抽样已完成说成老师首判全量已分析。
- 不要求家长重复上传已有且可访问的原图；先利用已存照片和记录。仍有关键缺口时标明待核查，只在当前判断确实需要时询问最少信息。
- 日常读取本次所需知识点、近期错因、当月学校作业及已有首判证据，按新增或变动增量核查，不每天重扫整库。每日自动出题须先过原有真实答卷门槛；未通过时仍安静跳过，不借资料审核发送催交或新题。
- 周报按真实日期引用已核实校内首判与其他练习证据，分别统计后综合调整复查重点。日期未知的历史学校作业可作历史风险线索，不能冒充本周新作答或给出伪精确正确率。
- 写入后按任务要求重新读取，确认新增信息确实保存；无法保存时说明限制，不宣称已接入。**所有学生原答、老师具体评论、学校照片、私有链接、成绩与掌握状态仅存私有目录；公开仓库只存通用规则和空白模板。**
