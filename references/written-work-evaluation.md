# 全学科：书面呈现、板书／纸面布局与书写方法评价

> 所有学科通用。收到孩子的手写作业、书面答卷、作文、默写、图表、板书或电子笔截图时，不仅判知识内容与结果，还要评价**实际可见的书写呈现方式**。学科的评分、语言、题型比例与掌握升级仍服从 `subjects/*.md`；本文件只规定新增的书面评价维度与证据边界。

## 1. 默认评价的三个独立维度

1. **内容与解题要求**：答案、逻辑、中间步骤、规定的式子／单位／图／标点／说明是否正确齐全。按原题明示要求计分，不能以字漂亮替代知识正确。
2. **版面组织（板书／纸面布局／ノートの書き方）**：题号能否定位；标题、步骤、算式、草稿、正式答案是否区分；行距、对齐、分栏、留白、书写顺序和订正位置是否便于自己检查与老师阅读。只按上传画面的可见范围评价；裁掉的页面不能据此判整体布局。
3. **字形与书写表达**：文字／数字／运算符能否辨认，字的大小与比例、行内位置、笔画形态、间距、上下左右结构或对应语言的大小写、标点等是否符合已学规范。检查可见的“写出来是什么样”，不凭最终照片猜手部动作、持笔姿势、运笔轨迹、笔顺或笔画书写先后。

## 2. 分学科观察点

| 学科 | 版面组织 | 字形与书写方式 |
| --- | --- | --- |
| 数学（算数） | 题号；横式与竖式分开；个位／十位／百位对齐；加减乘除符号、等号、进退位／借位标记清楚；多步骤依次排列，单位和最终答案显眼；画图有标签、必要时直尺使用痕迹／标注 | 数字0/6/8、1/7、2/7等可辨；+、−、×、=不混；单位m/cm、L/dL、こ/まい清晰；图表线段、箭头和标注足以表达数学意义 |
| 中国小学语文 | 题号、答题空、段落开头、行间距、作文分段、标题和标点位置、订正保留可核查 | 汉字笔画是否缺／多、偏旁部首位置、左右／上下结构、田字格占位、大小与间距；拼音声调位置和字母清晰。笔顺要有连续视频或可核实分步证据 |
| 日本小学国語 | 原稿用紙／マス的行列使用、段落开头、題名、句読点、漢字とかなの位置、訂正的位置 | ひらがな／カタカナ／漢字の字形、部首・はね／はらい等最终可见形态、送り仮名、濁点・半濁点、字の大きさと間隔。筆順は静止画のみでは判定不可 |
| English | 题号、单词与单词之间的空格、行距、句首与句末、填空／连线／订正位置 | 大小写、b/d、p/q等易混字母、字母高低和方向、单词内部字母间距、句号／问号／撇号；若使用四线格，观察基线和升／降部位置。口语和发音不能由纸面推断 |

## 3. 评价与计分的边界

- **终点必须给出具体书面反馈**：在整次练习的有效题全部按要求订正完成后，简短给出一处做得好的书写或布局行为，最多1–2项可操作的改进建议（例：「①のひっ算は位がそろっている。②は式と答えを別の行に書こう」）。不逐笔罗列瑕疵、不空泛地只说“字要工整”。语言跟随学科：算数／国語用日语，中文按中文规则，英语反馈用适合孩子理解的语言。
- 将 **答题是否按要求完成** 与 **书面清晰度／美观改善建议** 分栏记录。原题明确要求笔算、图、单位、规范格式而缺失时，按该题原规则评为未完整；若数字、推理、要求都符合但排版不美观，则保持知识得分，不因字不漂亮另扣分或降低掌握L级。
- 看不清的字／符号标“判读待确认”，必要时请局部补拍或请孩子按题号说明；不凭猜测硬判错误，也不以照片光线、拍摄角度、橡皮擦痕直接判断孩子书写能力。孩子写字速度、握笔、坐姿、用力、笔顺、笔画路径，**只有可观察的连续动作视频、可靠分步图或现场描述**才能评价，缺证据时写“书写动作／笔顺未观察”，不推断。
- 对所有年级依据**已经教过的书写规范**和原题要求评价，不因学生的书法审美、笔迹个性或身体差异作道德化评价；能辨认、能复查、符合题型要求优先。
- 没有实际笔迹（打字、纯口头、语音转写或仅成绩汇总）时，仍可评价内容，但**书面布局／字形标“未观察”**；不要为了形式而每日强制另做抄写。已有长期训练比例保持：中文不日常单独刷写字题、英语初学以听说为主、数学固定10题结构不变。

## 4. 完成本次练习后，统一向孩子反馈（所有学科强制）

- **阶段区分，不能提前讲评**：首次提交或后续中途提交时，助手必须在内部核对原题、孩子笔迹及应有的格式，**私有记录首次正确数及每道题的错因、书面布局和字形观察**，但**不要对孩子公布完整分数、详细错因分析、优点总结、写字与板书评价**；也不要提前给家长转发面向孩子的完整报告。
- **订正进行中只做操作性沟通**：简短告知仍需检查／补写的题号或判读待确认部分，集中请孩子自行订正和一次提交，例如「②と⑩をもう一度見直して、まとめて送ってね。」无需逐题夸奖或讲评；第一次尽量**只给题号**，不预先点破具体错点或正确答案。只有孩子自查仍错误、同类反复、表达不懂或主动求助时，按科目规则最小化说明需要核对的范围，必要时给针对性提示，**不把针对某一步的必要帮助扩展为整份练习的终点评价**。
- **最终反馈触发点**：本次练习所有**有效题目**均已按题目要求正确完成（包括明确要求的单位、式子、图、标点、说明等），并可靠收到对应的**最后一次订正／补交**，才在同一条回复中进行完整反馈。原题无效的部分排除；只看最终数字、尚欠指定过程／单位、笔迹无法辨认时，不视为全部完成。不强制孩子先做额外的升级变式才能结束原卷，但如双方已明确将追加题纳入本次练习，则以约定范围为准。
- **终点反馈的内容**：说明本次**首次完整正确数与最终完成情况分开**，依据最初真实作答和历次订正，说清楚做得好的知识点、哪些题起初没做好及**具体错点和当时产生错误的位置**、是独立自查还是经提示完成；再从可见笔迹中给一处板书／版面／字形优点和至多两项改进建议，以及下次复查目标。面向孩子使用对应学科语言。不能在中途只因已经计算出首答分数就提前发这段反馈。
- **未完成／暂停**：孩子到时或主动结束时，允许停止并私有标记「未完成／待订正」，**不强迫做至全对**，也不把未完成题当错题。只简短确认剩余题号和可继续的状态；不自动发布完整评价。如家长另行明确要求阶段性报告，可给家长说明截至此刻的已核实事实，但明确它不是给孩子的终点反馈，不修改首次成绩。
- **严守证据与分层计分**：每次原答和订正均在后台保存，最终10/10不回写首次8/10；需要帮助时记录提示等级。书写建议不用于替代数学／识字／阅读成绩；静态照片仍不能证明笔顺、动作或发音。学校老师首判与AI作答继续分开。

### 仅提取文字观察，避免重复存储笔迹照片

- 直接查看用户已提交的原图，记录每题关键字、数字／算式、书写错误位置、版面和字形的可见现象（例如“等号后数字贴得太近”“竖式十位未对齐”）、修正前后区别；不另行保存原始图像、裁剪图或新截图至 Library。
- 首次和中途的观察先保留在会话内部，全部有效题完成后的最终讲评才集中同步必要的私有文字摘要；使用能够合并多个文件变更的批量写入，避免三次或更多单文件覆盖确认。如没有免确认的持久写入权限，不反复触发审批，只说明尚未同步。
- 文字化观察不能替代重新查看原图；照片以后不可用时，标注“原图不可复核”，不能从摘要断言真实笔顺、握笔、运笔轨迹或未见部位的布局。

## 5. 反馈和记录闭环

- 完成所有有效题后的**终点反馈**分两部分：`正誤・内容` 和 `書き方／ノートの書き方`（中国语文可写“答案与表达／书写与排版”）。点名**具体题号与可见现象**，解释首次错点与已经完成的订正；完成前仅操作性提示仍待订正题号，需要时再给最小辅助，不提前展开总评。
- 私有 `progress.md`：按学科和相应能力标签记录 **内容错误** 与 **书写呈现改进点**，例如“数位对齐”、 “字形结构”、“标点占格”、“英文大小写”，写明证据及下次检查目标。书写问题可以设置单独复查频率，不被错误归类为运算不会或不认识字。
- 私有 `study_log.md`：首次及中途提交先在**本次会话内部**记录原始得分和观察证据，标明“终点评价待全部完成”；最后一次有效题全部完成后，按最低外部写入策略同步文字证据并记录已经向孩子提供的终点反馈、可观察的版面优点、最多2项重点和订正变化；记“只凭静态图未评笔顺”时不另设题。保存实际孩子的记录只限私有 Library／授权云端，不写公开 GitHub。
- 学校老师的首次批改仍按 `references/school-homework-evidence.md` 独立保存；老师画圈与否不能替代独立的字形／排版观察。内容首判成绩、书面规范建议、订正后改善是三个不同字段，绝不相互覆盖。
- 新学期继续使用同科原 `progress.md`／`study_log.md`；不得重置之前掌握等级。只有观察到了真实改进才更新书写能力，不凭出题或未提交作业推断能力。
