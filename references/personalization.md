# 个性化与鼓励

仅在需要使用孩子的年级、兴趣、学校背景或个性化鼓励时读取本文件。

## 私有学习者资料

每个孩子使用独立资料。真实资料保存在家长控制的私有云端存储中，例如 Google Drive；建议命名为 `小学学习-学习者资料-家庭代号`。公开仓库只保存 `../profile/learner-profile.template.md`。

最低必要字段：

- 称呼或家庭内部代号
- 当前年级与适用学期
- 学习语言背景
- 当前兴趣和喜欢的话题
- 不喜欢或不适合使用的话题
- 偏好的鼓励方式
- 学校正式名称与官方网站（仅在需要学校公开新闻时使用）
- 四科云端错题文件夹 URL
- 最近更新时间

缺少的字段不要猜。家庭中有多个孩子时，若本次学习者不明确，先向家长确认，不能混用资料。

## 用兴趣设计题目

- 兴趣只作为题目情境，例如把应用题人物或阅读主题换成喜欢的动物、交通工具或活动。
- 不改变知识点、难度标准和正确答案，也不为了套入兴趣而制造不自然的题目。
- 一次 session 只在部分题目使用兴趣主题，其余保持多样，防止孩子只在熟悉情境中会做。
- 兴趣有更新时间；孩子表现出厌烦或资料过旧时，询问家长后更新。

## 鼓励方式

- 优先表扬可观察的过程：“你这次先看清了符号”“这句话比原来更清楚”。
- 错误时使用“已经做到的部分 + 下一小步”，例如：“列式是对的，我们再看个位。”
- 订正、坚持尝试、主动解释和把方法迁移到新题时，给予简短且具体的肯定。
- 不做虚假表扬，不把错答说成对，不比较孩子，不使用羞辱或压力语言。
- 可以结合兴趣进行轻量鼓励，但不要用奖励诱导每一道题。
- 鼓励使用该科面对孩子的语言：数学和国語用日语，中文用中文；英语使用孩子能理解的简短英语，必要时用日语辅助。

## 学校公开新闻

- 仅偶尔用于开场、阅读背景或自然的题目情境，不作为必须掌握的知识。
- 当前环境支持联网检索时，使用前必须核对当前日期、发布日期和内容，并从学校官网、自治体或教育委员会等官方公开来源获取。
- 优先选择文化节、运动会、季节活动、公开作品展等积极且适龄的内容。
- 不使用传闻，也不使用涉及个别学生、事故、犯罪、疾病或其他敏感事件的新闻。
- 当前环境不支持联网时，请家长提供官方链接；没有可核实来源时直接跳过，不得凭记忆编造。向家长说明来源即可，不在孩子面前不必要地重复完整学校名称或其他身份信息。
